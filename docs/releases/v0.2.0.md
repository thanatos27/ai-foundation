# AI Foundation v0.2.0

Release date: 2026-10-25

## Highlights

AI FoundationのMVP v0.1.0以降の機能追加をまとめたリリースです。Source of Truthを既存のサービスに保持しつつ、AIから管理できる対象と操作を拡張しました。

- **Task / Todoist**: 繰り返しタスクの作成・取得・変更・完了時の動作をサポート（Issue #11）。
- **Schedule / Google Calendar**: 複数の書き込み先Calendarを別名で選択可能に。開催期間の終日イベントと通常の予定の使い分け、説明欄・場所、単発イベントの部分更新をサポート（Issue #12）。
- **Areas / Notion**: PARAの継続的な領域を目次ページとして一覧・取得（Issue #13）。
- **Life Log / Obsidian**: 旅行・外出・イベント等の不定期な記録をKnowledgeとは別のMarkdownとして作成・取得・追記（Issue #14）。

## Compatibility / Migration

- Google Calendarの設定 `sources.schedule.writable_calendar_id` は廃止。以下に置き換えてください。

```yaml
sources:
  schedule:
    provider: google_calendar
    default_calendar: personal
    writable_calendars:
      personal: "<AI Foundation calendar ID>"
      events: "<Event Catalog calendar ID>"
```

- Google Calendarの `#attended` 判定と `schedule_list.attended_only` は廃止しました。参加実績の専用フラグは扱わず、必要な記録は通常の予定・説明欄で運用してください。
- AreasおよびLife Logの設定と初期セットアップはREADMEを参照してください。

## Scope / Future Work

- Google Sheetsの関連資料URLは既存のMarkdown本文、Notionページ、GitHub README等に記載して参照する運用としました。独立したReference機能は導入しません（Issue #16はNot plannedとしてClose）。
- Google Calendarの繰り返しイベント更新は対象外です。LLM Client Verificationは任意です。
